# Nvisco Website

Source for [nvisco.com](https://nvisco.com), the website of Nvisco, a hardware engineering partner for intelligent systems and robotics. The site covers PCB design, mechanical CAD and embedded firmware, from first sketch to a product ready for launch.

## Overview

A static website hosted on GitHub Pages with a custom domain. It has no build step, so every change to the files is published directly.

## Pages

| File | Purpose |
|---|---|
| `index.html` | Main landing page with services, process, work samples and contact |
| `join.html` | Team application page |
| `dashboard.html` | Site health dashboard generated by the Nvisco Engine |
| `sitemap.xml` and `robots.txt` | Search engine indexing |
| `CNAME` | Custom domain configuration |

## Related Repositories

- [nvisco_engine](https://github.com/zainhaider626/nvisco_engine): automation for site audits, content drafting and search submission

## Editing

1. Edit the HTML files directly.
2. Keep images next to the pages and compress large files before upload.
3. Commit to `main`. GitHub Pages publishes the update automatically.

Preview locally with:

```bash
python3 -m http.server 8000
```
